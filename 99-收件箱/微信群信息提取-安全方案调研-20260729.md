# 微信群信息提取 · 安全方案调研

## 核心发现

三种技术路线：

| 方案 | 原理 | 封号风险 | 门槛 |
|------|------|---------|------|
| **本地数据库解密** ✅ | 从微信本地加密DB提取→LLM总结 | 极低（不碰网络协议） | 需要获取数据库密钥 |
| UI自动化 | 模拟鼠标键盘操作 | 中（行为模式异常） | 低，但稳定性差 |
| Hook注入 | 注入微信进程 | 高（被检测即封号） | 高，Windows签名验证 |

**结论：本地数据库解密是目前唯一安全可行的方案。**

## 候选工具

### 1. wechat-digest ⭐ 首选
- GitHub: cliffyan28/wechat-digest
- 功能：扫描微信进程内存获取密钥 → 解密本地DB → LLM生成每日摘要 → 输出Markdown/PDF
- 优势：专门为"群聊每日摘要"设计，需求完全对口
- Windows支持：✅

### 2. Chatlog MCP
- 功能：解密微信DB → HTTP API → AI工具（通义灵码/Claude等）直接读取
- 优势：MCP协议，可以接入Cola/Alice工作流
- Windows支持：✅

### 3. mac-wechat-summary
- 平台：macOS
- 功能：自动刷新密钥、重新同步数据库
- 局限：纯Mac方案，我们有Windows

## 安全原理

```text
微信本地数据库（加密SQLCipher）
        ↓
获取密钥（从微信进程内存读取，纯本地）
        ↓
解密 → 提取聊天记录（不经过微信服务器）
        ↓
本地LLM处理 → 生成摘要
```

全程不调用微信任何API、不模拟操作、不注入进程。微信服务器完全感知不到。

## 建议方案

**wechat-digest + Cola 集成：**

```text
每日定时（如凌晨2点）
  → wechat-digest 解密本地DB
  → 提取指定群聊的最近24h消息
  → LLM生成结构化摘要（话题/资源/待办/金句）
  → 输出Markdown到 G:\A01-15\ 每日摘要\
  → Cola 早上读取，整理到飞书知识库
```
