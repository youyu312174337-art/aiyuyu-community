# AI社群运营 · 基础知识库

## 1. 社群类型

| 类型 | 目的 | 运营方式 | 例子 |
|------|------|---------|------|
| 兴趣群 | 聚集同好、交流讨论 | 弱管理、重内容 | 番茄音乐群 |
| 学习群 | 共同学习、互相监督 | 结构化引导 | AI知识库学习群 |
| 用户群 | 产品/内容受众 | 信息发布+反馈收集 | AI有语读者群 |
| 共创群 | 一起做项目 | 强协作、任务驱动 | AI音乐创作群 |

## 2. 社群运营节奏

```text
日常    → 有价值的信息分享（AIHOT/工具/案例）
每周    → 一个讨论话题/一个挑战
每月    → 一次复盘/一次活动
```

## 3. 信息提取（核心难点）

- 微信群：封闭生态，需本地数据库解密方案（wechat-digest待实测）
- 飞书群：Alice可直接参与并提取
- 原则：不是从微信里提取，是把值得提取的内容引导到可提取的平台

## 4. 社群增长

- 公众号文章底部引流
- 群内成员邀请（口碑）
- 跨群联动
- 内容→关注→进群→内容 正向循环

## 5. 内容复用

群里的讨论 → 知识库归档 → 公众号选题 → 文章发布 → 群内讨论 → 循环
